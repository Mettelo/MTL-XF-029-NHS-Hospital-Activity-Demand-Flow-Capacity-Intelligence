# MTL-XF-029 — Team delivery and submission

**Project:** NHS Hospital Activity, Demand, Flow & Capacity Pressure Intelligence

**Decision:** Which hospital activity streams show sustained change requiring planning investigation, and what capacity, waiting-list and workforce evidence is still needed to diagnose service pressure?

The master repository is the Mettelo-controlled specification. Create `MTL-XF-029-<team-name>` under the **Mettelo GitHub organisation** and deliver your work there. Add all members through their individual GitHub accounts.

1. Follow [Team Repository Standard](TEAM_REPOSITORY_STANDARD.md).
2. Check D1–D12 in [Deliverables](../project/DELIVERABLES.md) and AC1–AC12 in [Acceptance Criteria](../project/ACCEPTANCE_CRITERIA.md).
3. Follow [Submission Guide](SUBMISSION_GUIDE.md) for evidence, handover and the simulated panel review.
4. Complete [Final Submission Template](FINAL_SUBMISSION_TEMPLATE.md) in your team repository.

The review examines decision relevance, 8 governed measures, source/cohort evidence, reproducibility, five supported findings, two priority scenarios, five reconciled BI measures, ten UAT cases and actual contributions. Presentation polish cannot replace evidence.

This is a **simulated confidential-client engagement** using official public/open data. The client label is fictional and intentionally anonymous. Do not imply a real external Mettelo customer, employment by that client, privileged access or confidential source data. Public source statistics remain public; the engagement framing does not make them confidential.
